# kotlin-rss-reader

## 기능 요구 사항

기술 블로그를 모아 나만의 블로그 모음을 만들어 보자.
각 기술 블로그에 새로운 글이 게시되면 해당 사이트의 RSS가 업데이트된다.
각 기술 블로그의 글을 수집하여 작성된 날짜별로 내림차순으로 정렬하여 최대 10개의 글을 표시한다.
찾고자 하는 단어를 입력하면 제목에 해당 단어가 포함된 게시물이 표시된다.

## 선택 요구 사항

한 번 실행하면 10분마다 기술 블로그의 RSS 업데이트를 확인한다.
새 글이 발견되면 사용자에게 메시지로 알린다.
기존 기능 요구 사항은 계속 작동할 수 있어야 한다.

---

- [x] 기술 블로그들의 RSS 피드를 읽는다,
- [x] 최신 글 10개를 날짜 내림차순으로 정렬하여 출력하고,
- [x] 검색어에 따라 제목을 필터링하여 보여주는 기능을 가진다.

## 기능 목록

FeedSource

- [x] RSS 피드 URL을 저장한다.
- [x] 피드 URL에서 Document 데이터를 읽어온다. (fetchedDocument)

Article

- [x] 기술 블로그의 글 정보를 저장한다.
- [x] 제목, 링크, 작성 날짜, 설명
- [x] Comparable을 구현하여 날짜 기준으로 내림차순 정렬, 제목 기준으로 오름차순 정렬



ConsoleView

- [x] 키워드 입력을 통해 사용자 검색어를 받아온다.
- [x] 콘솔 혹은 텍스트 입력에서 키워드를 입력받을 수 있어야 한다.
- [x] 게시물 리스트를 출력 형식에 맞게 출력한다.
- [x] 제목, 날짜, 링크 등을 정리해서 보여준다.
- [x] 새로운 글이 발견되면 콘솔에 메시지로 알려준다.


FeedSources

- [x] 여러 RSS 피드를 수집하여 통합된 게시물 리스트를 만든다.
- [x] 게시물들을 날짜 내림차순으로 정렬한다.
- [x] 최대 10개의 게시물만 출력하도록 제한한다.
- [x] 입력된 키워드를 기준으로 제목에 해당 키워드가 포함된 게시물을 필터링한다.
- [x] 검색 결과도 10개 이하로 제한한다.
